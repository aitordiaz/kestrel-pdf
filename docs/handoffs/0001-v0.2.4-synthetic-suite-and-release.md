## 4. Key Architectural Discoveries

1. **UTF-8 Multi-Byte String Decoding**:
   - `lopdf::Document::decode_text(None, bytes)` assumes PDFDocEncoding for unencoded Type 1 strings, corrupting multi-byte UTF-8 accented characters like `Ó`.
   - Checking `std::str::from_utf8(bytes)` first correctly preserves international Spanish accented characters (`CERTIFICACIÓN`).
2. **Page Coordinate Mapping Across 4 Rotations**:
   - Rotations 90° and 270° swap visual dimensions ($W \leftrightarrow H$).
   - `map_pdf_point_to_visual(x, y, W, H, rot)` maps bottom-left PDF coordinates $(x, y)$ to top-left screen visual coordinates $(vx, vy)$:
     - 0°: $(x, H - y)$
     - 90°: $(y, x)$
     - 180°: $(W - x, y)$
     - 270°: $(H - y, W - x)$
