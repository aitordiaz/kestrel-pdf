# HANDOFF-0002: Image Placement, Alpha SMask & AcroForm Layout Fidelity

- **Date**: 2026-10-07
- **Author**: Antigravity Pair Programmer
- **Active Version**: v0.2.6
- **Active Branch**: `fix/image-placement-and-form-rendering`

## 1. Executive Summary

Resolved high-impact visual fidelity defects reported on complex invoices and administrative form documents:
- Embedded images placed with inverted vertical scale (`cm [w, 0, 0, -h, x, y]`) are now mapped using full 4-corner affine bounding boxes, correcting a $2 \times h$ vertical translation error that previously detached category icons and illustrations from text lines.
- JPEG streams and Flate images with soft masks (`/SMask`) decode cleanly with transparent alpha channels, removing black backgrounds around icons.
- AcroForm widgets no longer enforce arbitrary `.max(20.0)` height or `.max(24.0)` width constraints or opaque 78% blue fills, preventing occlusion of document lines, prompts, and underlines.
- Form field values encoded in UTF-16BE (with BOM `0xFE, 0xFF`) are properly decoded into standard UTF-8 strings (e.g. `ELENA VÁZQUEZ PEÑA`).

## 2. Key Accomplishments & Code Modifications

1. **`crates/kestrel-core/src/document.rs`**:
   - Replaced naive `transform_point(0, 0)` image extraction with full 4-corner affine bounding box projection:
     `min_x = p0.x.min(p1.x).min(p2.x).min(p3.x)`, `max_y = p0.y.max(p1.y).max(p2.y).max(p3.y)`.
   - Added JPEG container detection via magic bytes `[0xFF, 0xD8, 0xFF]` using `image::load_from_memory`.
   - Added `/SMask` soft mask stream decompression and alpha channel injection into RGBA pixel buffers.
   - Added DeviceCMYK to RGB pixel conversion support.
2. **`crates/kestrel-core/src/forms.rs`**:
   - Added `decode_pdf_form_string` supporting UTF-16BE strings (BOM `0xFE, 0xFF`) and PDFDocEncoding fallback.
3. **`crates/kestrel-app/src/app.rs`**:
   - Removed `.max(20.0)` / `.max(24.0)` minimum size enforcement on form fields, using exact PDF bounding boxes `(fw * zoom, fh * zoom)`.
   - Replaced near-opaque `rgba(239, 246, 255, 200)` fill with transparent rendering in `Pan` mode and a non-occluding 18% translucent tint `rgba(219, 234, 254, 45)` in `FormFill` mode.
   - Proportional font scaling for form values: `(f_h * 0.82).clamp(7.0, 32.0)` with padding.
4. **Testing Suite Expansion (32 Tests Passing Workspace-wide)**:
   - Added `test_integration_inverted_ctm_image_bounding_box_and_placement` in `kestrel-core`.
   - Added `test_integration_image_smask_transparency` in `kestrel-core`.
   - Added `test_integration_utf16be_form_field_decoding` in `kestrel-core`.
   - Added comprehensive synthetic regression tests covering exact placement, soft masks, and UTF-16BE decoded form assertions.
