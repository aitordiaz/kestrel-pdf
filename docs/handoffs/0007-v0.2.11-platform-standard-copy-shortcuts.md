## 1. Executive Summary

In response to the user request ("allow to copy with standard shortcuts in each platform"), this release delivers full native and platform-standard keyboard shortcut support across all supported environments (macOS, Windows, Linux, and WebAssembly).

Key additions:
1. **Multi-Platform Copy Shortcut Matrix**:
   - macOS: `Cmd+C` (`⌘C`) via `modifiers.mac_cmd` / `modifiers.command`.
   - Windows & Linux: `Ctrl+C` via `modifiers.ctrl` / `modifiers.command`.
   - IBM CUA Standard: `Ctrl+Insert` on Windows and Linux.
   - Multimedia/Hardware: Dedicated `Key::Copy` key.
   - OS & Browser Integration: Native `egui::Event::Copy` clipboard events.
2. **Text Input Focus Guard**:
   - Checks `ctx.wants_keyboard_input()`. When a text input field (e.g. search query or form field) has focus, document-level selection shortcuts do not hijack the clipboard from active text edits.
3. **Select All Shortcut (`Ctrl+A` / `Cmd+A`)**:
   - In `ActiveTool::SelectText` mode, standard select-all shortcuts select all text runs on the active page and populate clipboard selection.
4. **Platform-Adaptive UI Tooltips & Badges**:
   - Toolbars and right-click context menus dynamically display native shortcut badges: `⌘C` on macOS and `Ctrl+C / Ctrl+Ins` on Windows/Linux.

## 4. Current Architecture & System State

```
Platform Event / Key Event
      │
      ▼
ctx.wants_keyboard_input()?
   ├── Yes ──► Delegated to active text widget (search box, form edit)
   └── No  ──► Document Selection Engine:
                 ├── is_copy_shortcut_pressed() ──► copy_selected_text / copy_selected_image
                 ├── is_select_all_shortcut_pressed() ──► select_all_current_page()
                 └── Key::Escape ──► clear_selection()
```
