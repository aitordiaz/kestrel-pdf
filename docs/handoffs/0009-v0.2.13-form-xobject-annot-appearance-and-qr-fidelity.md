## 1. Executive Summary

In release **v0.2.13**, Kestrel-PDF resolves critical visual rendering omissions on complex administrative and officially signed PDF documents:
1. **Electronic Signatures**: Extracted from `/Annots` normal appearance streams (`/AP /N`), properly resolving Form XObjects (`/Subtype /Form`), nested forms (`/FRM`, `/n2`), signature text, and visual seal stamps.
2. **Margin Verification Strips**: Processed Form XObjects (`Do /Name`) within page content streams, faithfully rendering right-margin vertical validation metadata (CSV / CVD verification codes, verification URLs, and pagination).
3. **1-Bit Monochrome QR Codes**: Implemented standard PNG predictor unfiltering (None, Sub, Up, Average, Paeth) for `Predictor 10..=15` alongside 1-bit scanline bit unpacking (`BitsPerComponent 1`), fixing 35x35 QR code distortion and white truncation.
4. **Rotated Text Rendering**: Captured rotation matrices (`Tm` and CTM) into `PositionedText.rotation_deg`, visually rendering rotated text via `egui::epaint::TextShape::with_angle` with accurate visual bounding boxes for search highlighting and text selection.

All implementations strictly adhere to the repository privacy invariants: **0 disk PDF files, 0 local filesystem references, and 0 user or municipal PII**.

## 2. Key Accomplishments & Changes

### A. Core Engine (`crates/kestrel-core`)
- **PNG Predictor Unfiltering (`unfilter_png_predictor`)**: Implemented RFC 2083 / ISO 32000-1 §7.4.4.4 predictor algorithms supporting None (0), Sub (1), Up (2), Average (3), and Paeth (4) predictors.
- **1-Bit Image Bit-Unpacking**: Added support for 1-bit monochrome images (`BitsPerComponent 1`, `/DeviceGray`), mapping single bits directly to 0 (black) and 255 (white) without truncation.
- **Form XObject Recursive Engine**:
  - Extracted `process_content_operations` with bounded recursion depth (`depth < 8`) to eliminate circular references.
  - Implemented `ResourceContext` for hierarchical inheritance and merging of fonts, ToUnicode CMaps, encodings, and sub-XObjects.
  - Applied Form XObject `/Matrix` transformations to the current graphics transformation matrix (CTM).
- **Annotation Appearance Stream Extraction**:
  - Inspected `/Annots` on every page and processed `/AP /N` Form XObjects.
  - Mapped appearance `/BBox` to annotation `/Rect` in user coordinates.
- **Rotation Geometry**:
  - Added `rotation_deg: f32` to `PositionedText`.
  - Updated `text_run_visual_bounds` to swap width and height for vertical/orthogonal text orientations.

### B. Application Frontend (`crates/kestrel-app`)
- **Rotated Text Visualization**: Updated text rendering in `render_ui` to render rotated text runs using `egui::epaint::TextShape::new(pos, galley, color).with_angle(angle_rad)`.
- **Search Highlighting**: Enhanced search highlight rectangles to use `text_run_visual_bounds`, properly highlighting rotated text runs.
- **E2E Smoke Testing**: Added `test_e2e_form_xobject_and_rotated_signature_rendering_smoke` validating Form XObjects, electronic signature appearance streams, and rotated verification codes directly in an egui frame.
