## 1. Executive Summary

Release **v0.2.14** modernizes the visual styling, user experience, and navigation model of Kestrel-PDF:
1. **In-Flow Page Navigator (`[ ◀ Prev ] [ 1 ] / 4 [ Next ▶ ]`)**: Replaced the noisy left sidebar page list with an interactive, centered navigation pill in the toolbar, featuring a direct editable page number text box, rapid stepper buttons, and safe bounds clamping.
2. **Distraction-Free Canvas Focus**: Left sidebar is closed by default (`sidebar_open = false`), providing 100% horizontal screen width for document reading with zero distractions.
3. **Professional Warm Salmon & Light Ochre Palette**: Established design tokens (`#D97757` salmon, `#E28743` ochre, Slate 900/800 panels, Slate 700 borders) with high contrast meeting WCAG AA/AAA standards.
4. **Elevated Primary CTA**: Prominent, high-affordance "Abrir fichero" buttons with comfortable hit targets in both the header bar and the empty state card.
5. **Reverent Document Viewport ("PDF As Is")**: 100% fidelity document rendering without tinting or interference, framed by a neutral slate background.
6. **Reusable `frontend` Skill**: Documented frontend patterns, tokens, and test recipes in `.agents/skills/frontend/SKILL.md`.

- **Sidebar Default**: Defaults to collapsed (`sidebar_open: false`), expandable on demand for outlines and metadata.
