## 1. Executive Summary

In response to user feedback regarding visual clutter from excessive 1px borders ("tiene muchos bordes... no respiran") and horizontal crowding when running in non-fullscreen windows ("cuando no está a ventana completa, los botones se apiñan"), this session overhauled Kestrel-PDF's visual ergonomics and toolbar layout engine.

1. **Borderless Airy Modern Aesthetics**:
   - Stripped harsh 1px borders from all idle secondary buttons, inactive segmented tools, pill containers, and header panels.
   - Restructured segmented controls into sleek, borderless native tabs: inactive items are clean borderless icons/labels with soft hover glows, while the active tool sits on a vibrant Warm Salmon pill.
   - Replaced heavy full-height vertical separators with discrete, 18px-high soft alpha-blended dividers (`Color32::from_rgba_unmultiplied(148, 163, 184, 45)`).
   - Generous button padding and breathing room throughout all panels.

2. **Adaptive Responsive Layout Engine**:
   - Introduced dynamic viewport breakpoints based on `ui.available_width()`:
     - **Wide (`>= 1050px`)**: Full descriptive labels and icons (`[✋ Pan]`, `[📝 Select]`, `[📋 Forms (N)]`, `[✏️ Edit Text]`, `[✍️ Sign Contract]`, `[🛡️ Redact]`), `[< Prev] 1 / N [Next >]`, full zoom presets (`Fit Page`, `Fit Width`, `Reset`).
     - **Medium (`780px .. 1050px`)**: Compact labels (`[Pan]`, `[Select]`, `[Forms]`, `[Edit]`, `[Sign]`, `[Redact]`), caret-only navigators `[<] 1 / N [>]`, compact zoom presets (`Fit`, `Reset`).
     - **Compact (`< 780px`)**: Iconic mode (`TOOL_*` icons only with complete tooltips and keyboard shortcut hints), compact search box, and dynamic title truncation down to 20–32 characters.
   - Guaranteed zero crowding, zero text squishing, and zero horizontal overflow even on narrow 680px windows.

3. **GPU Texture Clamping Safety**:
   - Added `clamp_rgba_image_to_max_side` helper protecting headless CI runners and low-spec GPUs with 2048 texture limits from panicking on large tiles at 500% zoom.
   - Clamped both asynchronous tile requests and embedded raster image textures to `ctx.input(|i| i.max_texture_side)`.

4. **Verification & Release**:
   - Automated test suite expanded to **57 passing tests** (29 smoke + 28 integration).
   - Added `test_e2e_responsive_toolbar_modes_at_different_viewport_widths` and `test_clamp_rgba_image_to_max_side_and_texture_safety`.
   - 8/8 GitHub Actions CI matrix checks green.
   - Merged PR #25 to `main` and published official GitHub Release `v0.2.17` with native binaries for Linux x64, macOS Apple Silicon, and Windows x64.

## 2. Key Architecture & Code Changes

- [`crates/kestrel-app/src/theme.rs`](file:///home/aitor/projects/kestrel-pdf/crates/kestrel-app/src/theme.rs):
  - Made `secondary_button`, `ghost_button`, and inactive `segmented_tool_button` borderless (`Stroke::NONE`).
  - Redefined `pill_frame()` with soft fill and `Stroke::NONE`.
  - Added `vertical_divider()` helper for subtle 18px soft lines.
  - Softened `Visuals::dark()` widget strokes.
- [`crates/kestrel-app/src/app.rs`](file:///home/aitor/projects/kestrel-pdf/crates/kestrel-app/src/app.rs):
  - Tier 1 Header: responsive open/save labels (`Abrir` vs `Abrir fichero`), dynamic title truncation based on width, and discrete dividers.
  - Tier 2 Ribbon: responsive breakpoint engine (`avail_w >= 1050.0`, `780.0..1050.0`, `< 780.0`) dynamically adapting tools, page navigators, zoom controls, and search bar.
  - Render pipeline: clamped tile requests and raster buffers with `clamp_rgba_image_to_max_side` preventing GPU texture dimension overflow panics.
- [`crates/kestrel-app/tests/smoke_test.rs`](file:///home/aitor/projects/kestrel-pdf/crates/kestrel-app/tests/smoke_test.rs):
  - Added `test_e2e_responsive_toolbar_modes_at_different_viewport_widths` asserting layout fidelity across 1400px, 900px, and 680px screen widths.
  - Added `test_clamp_rgba_image_to_max_side_and_texture_safety` verifying texture safety.
- [`.agents/skills/frontend/SKILL.md`](file:///home/aitor/projects/kestrel-pdf/.agents/skills/frontend/SKILL.md):
  - Documented borderless airy tokens, discrete dividers, and responsive breakpoint standards.
