## 1. Executive Summary

This engineering handoff documents the implementation and verification of search result navigation and exact word visual highlighting:
1. **Interactive Search Navigation**: Clicking any search result card in `SidebarTab::SearchResults` jumps and scrolls the continuous viewport directly to the match and page, synchronizing `current_page`, `page_input_text`, and card highlight status.
2. **Exact Word Visual Highlighting**: Replaced the previous coarse bounding box that highlighted the entire paragraph or `TextRun` with exact glyph substring bounding geometry calculated per match occurrence.
3. **Active Match Stepping & Distinguishable Accent Colors**: Active match highlighted in Warm Amber (`Theme::SEARCH_HIGHLIGHT_ACTIVE`) while other matches display in Sunny Yellow (`Theme::SEARCH_HIGHLIGHT_REGULAR`). Added previous/next stepper controls in the search toolbar with Enter-key navigation.

## 2. Changes Delivered

### crates/kestrel-app
- **`crates/kestrel-app/src/theme.rs`**:
  - Added `SEARCH_HIGHLIGHT_REGULAR`: `Color32::from_rgba_premultiplied(179, 169, 97, 180)` (Warm Sunny Yellow with opacity).
  - Added `SEARCH_HIGHLIGHT_ACTIVE`: `Color32::from_rgba_premultiplied(206, 120, 49, 210)` (Warm Amber with high contrast).
- **`crates/kestrel-app/src/icons.rs`**:
  - Added `CARET_LEFT` and `CARET_RIGHT` aliases for toolbar stepping.
- **`crates/kestrel-app/src/app.rs`**:
  - Added `selected_search_result: Option<usize>`, `scroll_to_page: Option<usize>`, and `scroll_to_search_match: bool`.
  - Added `navigate_to_search_result(idx)`, `next_search_result()`, and `prev_search_result()`.
  - Updated `execute_search()` to auto-navigate to the first match when search query is submitted or changed.
  - Implemented exact substring bounding box measurement within `TextRun` layout (`prefix_w`, `match_w`), drawing exact highlight rectangles on the canvas painter.
  - Added programmatic scroll targeting using `ui.scroll_to_rect(hl_rect, egui::Align::Center)`.
  - Fixed borrow-checker collisions in outlines and search results loops by deferring navigation mutations outside iteration blocks.
  - Updated search bar UI with counter label, Previous/Next navigation buttons, and Enter-key stepping.
- **`crates/kestrel-app/tests/smoke_test.rs`**:
  - Added `test_e2e_search_navigation_scroll_and_page_synchronization`.
  - Added `test_e2e_exact_word_search_highlight_bounds_not_whole_paragraph`.
  - Updated `test_e2e_multi_page_search_navigation_and_visual_highlighting`.
