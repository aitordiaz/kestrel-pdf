## 1. Executive Summary

Phase 3 of the Kestrel-PDF MVP Roadmap is fully designed, implemented, and verified with 100% test pass rate across the full cross-platform workspace.
This major milestone elevates Kestrel-PDF from an ultra-fast reader, form filler, and signing tool into a full-fledged in-place PDF editor and document organizer.
Users can now inspect, hit-test, and edit existing text runs in-place, insert new text boxes with arbitrary typography and colors, replace and delete embedded raster images (XObjects), insert new images, and reorganize the document page tree (insert blank page, duplicate page, delete page, reorder up/down) directly in RAM with zero disk I/O.

### B. Core Engine Mutations (`crates/kestrel-core`)
- **Page Tree Operations**:
  - `insert_blank_page(at_index, width_pt, height_pt)`: Dynamically creates new Page dictionaries, links to `/Pages` tree root, and updates `/Count`.
  - `delete_page(page_index)`: Removes page object reference with strict minimum 1-page guard.
  - `duplicate_page(page_index)`: Deep-clones target page object dictionary and resources.
  - `reorder_page(from_index, to_index)`: Reorders `/Kids` array entries in the root Pages dictionary.
- **In-Place Text Editing & Insertion**:
  - `modify_text_run(page_index, run_index, new_text)`: Decodes `/Contents` stream operators, locates matching text operator (`Tj`, `TJ`, `'`, `"`), replaces operands with escaped literal string bytes, and re-encodes.
  - `insert_text_box(page_index, text, x, y, font_size, color)`: Synthesizes standard Helvetica font resource in `/Resources /Font`, appends content stream block with `BT /F_Kest ... rg ... Tm (...) Tj ET`.
  - `delete_text_run(page_index, run_index)`: Removes operator from decoded content stream.
- **Image Manipulation**:
  - `replace_image(page_index, image_index, new_rgba, width, height)`: Replaces image stream dictionary dimensions and Flate-compressed RGB data.
  - `insert_image(page_index, rgba, width, height, x, y, width_pt, height_pt)`: Creates new `/Subtype /Image` XObject, registers in page `/Resources /XObject`, and appends placement operator `q ... cm /ImX Do Q`.
  - `delete_image(page_index, image_index)`: Removes image invocation operator and XObject dictionary.

### C. Frontend Shell (`crates/kestrel-app`)
- **Tools**:
  - `ActiveTool::EditText`: Click hit-testing on text runs or blank areas to open modal, configure text content, font size (DragValue), and color picker.
  - `ActiveTool::EditImage`: Click hit-testing on embedded images, selection bounding box, replace via native file dialog or delete.
- **Modal Window**:
  - Floating, resizable modal with live typography controls, multiline text editor, Delete Run button, Apply Changes, and Cancel.
- **Thumbnail Sidebar & Reordering**:
  - Quick action toolbar (`+ Page`, `Duplicate`, `Del`).
  - Row steppers (`▲`, `▼`) for instant page reordering.
- **Immediate Tile Invalidation**:
  - Cache clearing (`self.textures.clear()`, `self.image_textures.clear()`) ensuring instant visual feedback upon document mutation.
